# fmlmc-neoforge

Modpack oficial do servidor **Freddie Mercury Lanches**.

## Requisitos

Antes de começar, você precisará de:

* Uma conta Microsoft para Minecraft Java Edition.
* O aplicativo Modrinth.

## 1. Instalar o Modrinth App

Baixe e instale o Modrinth App:

https://modrinth.com/app

Após a instalação, faça login utilizando sua conta Microsoft.

---

## 2. Criar a Instância

1. Abra o Modrinth App.
2. Clique em **Create Instance**.
3. Selecione:

   * **Minecraft:** 1.21.1
   * **Mod Loader:** NeoForge
   * **NeoForge Version:** 21.1.230
4. Escolha um nome para a instância.
5. Clique em **Create**.

---

## 3. Instalar os Mods

1. Baixe o arquivo **mods-client-side.zip**.
2. Extraia o conteúdo do arquivo.
3. Abra o Modrinth App.
4. Vá até a instância criada.
5. Selecione **Upload files**.
6. Abra a pasta **mods-client-side**.
7. Copie todos os arquivos extraídos para dentro desta pasta.

---

## 4. Iniciar o Jogo

1. Retorne ao Modrinth App.
2. Selecione a instância criada.
3. Clique em **Play**.
4. Aguarde o carregamento dos mods.

---

## 5. Entrar no Servidor

Após iniciar o Minecraft:

1. Acesse **Multiplayer**.
2. Adicione o endereço do servidor fornecido pela administração.
3. Entre e divirta-se!

---

## Solução de Problemas

### O jogo não inicia

Verifique se:

* A versão do Minecraft é **1.21.1**.
* O carregador é **NeoForge**.
* A versão do NeoForge é **21.1.230**.
* Todos os mods foram copiados corretamente para a pasta `mods`.

### Erro ao conectar no servidor

Certifique-se de que:

* Todos os mods do pacote foram instalados.
* Nenhum mod foi removido ou alterado.
* Você está utilizando a versão correta da instância.

---

Bom jogo e divirta-se no servidor do **Freddie Mercury Lanches**!
